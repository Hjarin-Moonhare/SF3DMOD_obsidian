

# Editing

As the documentation is stored as plain-text markdown, any text editor could work. But Obsidian MD is the intended way.

## Editing: The intended way
Obsidian MD is the intended way to edit the documentation. However, on practice you can use any text editor.

1. Download [Obsidian MD](https://obsidian.md/)
2. Open Obsidian
3. Get [SF3DMOD/SF3DMOD_obsidian](https://github.com/SF3DMOD/SF3DMOD_obsidian), such as - clone it, fork it, your preferred way.
4. Open the cloned repository in Obsidian
5. Edit
6. Make a pull request to [SF3DMOD/SF3DMOD_obsidian](https://github.com/SF3DMOD/SF3DMOD_obsidian)
